## A5. 보안 4계층 구조 (v9.1 완성) ⭐

### gitleaks 설치 (API 키 유출 방지) ✅

```bash
brew install gitleaks
mkdir -p ~/.git-hooks
cat > ~/.git-hooks/pre-commit << 'HOOK'
#!/bin/bash
gitleaks protect --staged --no-banner 2>/dev/null
if [ $? -ne 0 ]; then
  echo "🚫 보안 경고: 코드에 API 키/비밀번호가 감지되었습니다!"
  echo "   .env 파일이 .gitignore에 있는지 확인하세요."
  exit 1
fi
HOOK
chmod +x ~/.git-hooks/pre-commit
git config --global core.hooksPath ~/.git-hooks
```

> AI Studio는 생략 (멀티 페이지 한번에 빌드 안 되므로)
> 방법 C: 스크린샷(PNG) + HTML/CSS 동시 참조 = 가장 정확

### 4-1. Claude에서 프롬프트 작성 → Stitch에서 디자인 → 다운로드

**🌐 Claude 웹에서 — Stitch 프롬프트 제작:**

```
비유: 인테리어 디자이너에게 줄 "주문서"를 먼저 작성하는 것

1. Claude 웹에서:
   "Findably 랜딩 페이지 디자인을 Stitch에서 만들 거야.
    PRD를 기반으로 레퍼런스 사이트를 찾아주고,
    Stitch에 넣을 프롬프트를 만들어줘.
    아래 디자인 규칙을 프롬프트에 포함시켜줘."

2. Claude가 해주는 것:
   ① 레퍼런스 사이트 3~5개 찾기
   ② PRD의 화면 목록 + 기능 정리
   ③ 디자인 시스템 규칙 포함한 Stitch 프롬프트 생성

⚠️ Stitch에는 DESIGN.md 입력 기능이 없으므로
   매 프롬프트마다 디자인 규칙을 직접 포함해야 함
```

**프롬프트 템플릿 (Claude에게 요청):**
```
[프로젝트명]의 [화면명] 디자인을 Stitch에서 만들 거야.
PRD 내용과 아래 디자인 규칙을 포함해서
Stitch에 붙여넣을 프롬프트를 만들어줘.

[디자인 규칙 — 매번 포함 필수]
- 폰트: Pretendard (본문), DM Sans (제목). Inter/Roboto/Arial 절대 금지
- 브랜드 컬러: #2b7cff (프로젝트별 변경)
- 배경: 오프화이트(#fafbfc) ↔ 흰색(#fff) 교차. 순백 단독 금지
- 다크 배경: 페이지당 최대 1곳
- 카드: 비대칭 크기 (균등 3컬럼 금지)
- 레이아웃: 좌우 50:50 대칭 금지 → 55:45 또는 60:40
- 보라→파랑 그라디언트 금지
- 텍스트에 opacity 사용 금지 (실제 색상값만)

레퍼런스 사이트도 3개 찾아줘.
```

**🎨 Stitch에서 — 디자인 + 다운로드:**

```
1. stitch.withgoogle.com 접속
2. Claude가 만든 프롬프트를 그대로 붙여넣기
3. 여러 디자인 변형 중 마음에 드는 것 선택
4. 채팅으로 수정 요청
5. 완성되면 2가지 다운로드:
   ① 스크린샷 저장 (PNG) ← 레이아웃 참조용
   ② "Download Code" 클릭 ← 정확한 색상/간격 수치용
6. 다음 화면도 Claude→Stitch 반복
```

**화면마다 반복하는 사이클:**
```
🌐 Claude: "랜딩 페이지 프롬프트 만들어줘" → 프롬프트 복사
🎨 Stitch: 붙여넣기 → 생성 → 수정 → 스크린샷 + 코드 다운로드
🌐 Claude: "대시보드 프롬프트 만들어줘" → 프롬프트 복사
🎨 Stitch: 붙여넣기 → 생성 → 수정 → 스크린샷 + 코드 다운로드
... (핵심 5~6개 화면 반복)
```

**Stitch 팁:**

✅ 레퍼런스 이미지를 캔버스에 드래그하면 비슷한 느낌으로 생성
